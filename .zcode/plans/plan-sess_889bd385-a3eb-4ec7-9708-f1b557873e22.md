## Goal
Replace the overcomplicated per-language `__t()` helper (file-writes, imports, HTTP sinks — what broke the Flutter build) with a single simple convention: the model writes its language's normal `print`/`console.log` carrying a **fixed prefix** (`DEBUGGING_zer`) + timestamp + point + values. Collection greps that prefix. No helper function, no imports, no file-I/O. Probe detection, the gates, and stripping all key off the same prefix.

## The marker
- Fixed prefix: **`DEBUGGING_zer`** (your token). Defined once as `export const DEBUG_MARKER_PREFIX = "DEBUGGING_zer"` and imported where regexes are built, so there's one source of truth.
- Per-session isolation is preserved: the trace file is still one-per-`traceId` (`${traceId}.log`); we just grep it for the prefix instead of the traceId.
